# MiraiDesk システム設計資料（開発部・架空・社外秘）

## システム構成
フロントエンドはReact、バックエンドはPythonのFastAPIで構築する。
データベースはPostgreSQLを使用し、検索機能にはElasticsearchを使用する。

## API の利用制限
| プラン | 1分あたりのリクエスト上限 | 1日あたりのリクエスト上限 |
|---|---|---|
| ライト | 60 | 10,000 |
| スタンダード | 300 | 100,000 |
| エンタープライズ | 1,200 | 無制限 |

## リリース手順
本番環境へのリリースは、毎週水曜日の22時から行う。
リリースの前に、ステージング環境で回帰テストを実施し、テックリードの承認を得ること。

## バックアップ
データベースは毎日深夜3時に全体バックアップを取得し、30日間保管する。

## 障害対応
重大障害が発生した場合は、30分以内に障害対応チャンネルで第一報を出す。
