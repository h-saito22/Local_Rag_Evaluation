# LoRA 学習用データ（すべて架空）

架空の会社「株式会社サクラ物流」の文書と、LoRA（RAFT 方式）の学習用 QA です。
評価用の「株式会社ミライテック」（data/docs）とは別の会社・別の部署にしてあり、評価の答えを覚える効果が入らないようにしています（10/19 決定：案B）。

## 目的（10/19 決定）
- 覚えさせるのは「中身」ではなく「読み方」：資料と質問の言い回しが違っても、同じ意味なら資料を使って答える
- 資料に答えがないときは「資料に記載がありません」とだけ返す（言い換えを学んで何でも答えるようにならないためのブレーキ）

## train_qa.csv（150件）
| type | pattern | 件数 | 中身 |
|---|---|---|---|
| same | | 15 | 資料と同じ言葉で聞く |
| paraphrase | 用語 | 19 | 言葉の言い換え（例：ビジネスカード＝名刺） |
| paraphrase | 組合せ | 19 | 2つの文・表の2列、または2つの見出しを合わせて答える |
| paraphrase | 換算 | 19 | 数値の計算・比較（例：家賃8万円×50%＝4万円 → 上限3万円） |
| paraphrase | 否定 | 18 | 「〜しなくていい？」「〜してもいい？」など否定・例外 |
| none | 近い資料あり | 30 | 話題は近いが答えがない。section の資料をひっかけとして context に入れる |
| none | 無関係 | 30 | どの資料にもない話題 |

- section が `|` 区切りのものは、答えに2つの見出しが必要（両方を context に入れる）
- answer は学習させる「お手本の回答」。結論を先に書き、言い換えの対応が分かるようにしている

## 評価との関係
- data/qa/qa_hard.csv（22問）：評価用の data/docs を使った難しめの問題。paraphrase 18（用語・組合せ・換算・否定）＋ none 4（近い資料あり）。LoRA の効果はここで測る
- data/qa/qa_v1.csv（48問）：そのまま。LoRA で悪化していないかの確認用
