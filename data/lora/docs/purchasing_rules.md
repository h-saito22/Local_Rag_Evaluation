# 株式会社サクラ物流 購買規程（購買部・架空・LoRA学習用）

## 発注の手順
物品を購入する場合は、購買申請システムで申請し、購買部が発注する。
社員が取引先へ直接発注してはならない。

## 相見積もり
1件30万円以上の購入は、2社以上から見積もりを取ること。
ただし、保守契約の更新など、既存の取引先との取引を継続する場合は、相見積もりを省略できる。

## 購入の承認者
| 金額 | 承認者 |
|---|---|
| 10万円未満 | 課長 |
| 10万円以上100万円未満 | 部長 |
| 100万円以上 | 役員 |

## 検収
納品物は、届いた日から3営業日以内に申請者が検収し、購買申請システムに登録する。

## 新規取引先
新しい取引先と取引を始める場合は、取引開始の10営業日前までに購買部へ与信審査を依頼する。

## 支払
取引先への支払いは、月末締め・翌月末払いを原則とする。
