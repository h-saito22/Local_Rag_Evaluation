# 株式会社サクラ物流 広報規程（広報部・架空・LoRA学習用）

## 取材対応
報道機関から取材の依頼を受けた場合は、個人で回答せず、広報部へ取り次ぐ。

## SNS
業務に関する内容を、個人のSNSに投稿してはならない。
会社の公式アカウントへの投稿は、広報部の確認を受けてから行う。

## ロゴの使用
会社ロゴを社外向けの資料で使う場合は、広報部が配布するデータを使う。
ロゴの色や縦横の比率を変えてはならない。

## プレスリリース
プレスリリースの原稿は、発表日の5営業日前までに広報部へ提出する。

## 展示会への出展
| 展示会の規模 | 申請期限 | 承認者 |
|---|---|---|
| 小規模（ブース1つ） | 開催の1か月前 | 広報部長 |
| 中規模（ブース2〜4つ） | 開催の3か月前 | 広報担当役員 |
| 大規模（ブース5つ以上） | 開催の6か月前 | 社長 |
